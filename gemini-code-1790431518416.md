# Azure Key Vault Integration with AKS via Workload Identity & CSI Driver

This repository provides an end-to-end setup guide to mount secrets from an **Azure Key Vault** into **Azure Kubernetes Service (AKS)** pods using **Microsoft Entra Workload Identity** and the **Secrets Store CSI Driver** (Azure Key Vault Provider).

This architecture replaces deprecated solutions (like AKS Pod Identity) with native OpenID Connect (OIDC) federation, eliminating the need to store static Azure credentials or connection strings inside Kubernetes secrets.
